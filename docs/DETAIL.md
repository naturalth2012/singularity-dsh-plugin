# Singularity · 社会形态演化模拟器

**同样的技术，不同的制度选择，结局相差数倍。**

这是一个可以拨动的 AI 时代社会推演器。它不预测未来，它回答一个条件问题：
如果技术沿这条路走，而我们这样组织社会，2050 年前后会落在哪里。

---

## 七个标签页

| 标签页 | 看什么 |
|---|---|
| **历史长河** | 2024–2060 的逐年演化。拖动时间轴，看每年的指标与阶段；点事件看它为什么发生。 |
| **演化引擎** | 十四个杠杆在这里。拖动它们，整条历史立刻重算——这是模型的心脏。 |
| **三岔路口** | 技术越线之后，四条引力争夺历史的方向。看清每条路通向哪，以及本路径实际走了哪条。 |
| **指标矩阵** | 七个核心指标的当期读数与历史轨迹，一次看全。 |
| **情景对比** | 六个预设剧本并排对照：结局、终年指标、租金压力、稳健性。 |
| **理论底座** | 模型的理论来源、四条反驳意见（每条都可攻击本模型的结论）、以及它明确不做什么。 |
| **模型体检** | 采样报告的只读展示：结局分布、租金分位、三条已知非对称的实测值。**这里是本模型最该被质疑的地方。** |

---

## 十四个杠杆

分四组，每个都是 0–1 的目标值：

- **技术（4）**：AI 认知能力、算力供给、自动化覆盖、能源约束
- **制度（4）**：公共产权占比、再分配强度、协调能力、俘获程度
- **社会（3）**：社会团结度、意义供给度、教育与再技能
- **摩擦（3）**：地理与资源约束、人口结构压力、外部冲击强度

拨动它们，观察结局如何改变。**最值得做的实验**：把技术四项全部拉满，然后只动
「公共产权占比」——你会看到同一个技术未来分裂成完全相反的两个世界。

## 在对话里直接问

这个插件同时把引擎暴露成三个工具，你可以在对话里直接问：

- 「把公共产权拉到 0.9，还会走向算力封建制吗？」
- 「基准线情景下，最该动哪个杠杆？」
- 「六种结局分别是什么，有什么区别？」

工具只读引擎、不改变任何状态。它给出的每一个数字都来自同一个模型，
与面板上看到的一致。

## 已知局限（请先读这段）

模型有意把话说清楚，包括它的弱点：

1. **它是条件推演，不是预言。** 它不回答「哪一年会发生什么」。同样的参数每次运行
   结果完全相同——这是确定性模型，不是随机模拟。
2. **政策是「换一条插值目标」，不是社会对政策的反应。** 你设定 2035 年干预，
   模型只是从那年改走另一条曲线；它不模拟反对、拖延、执行偏差。
3. **主轨前三个阶段由技术渗透单一变量决定。** 制度杠杆在这些阶段不起作用——
   它们只在越过技术闸门后才开始裁决。这是简化，也是可被质疑的地方。
4. **崩解引力系数 1.8 高于其余三条。** 这个数字没有独立实证依据，
   是本模型最该被攻击的设定。模型体检页记录了它的实测影响。
5. **租金压力是当期读数，没有存量积累。** 它不模拟「占有结构反过来强化自己」的回路。
6. **改良资本主义路径有硬性前提。** 产权高度公有化时（≥0.62）这条路的改良空间为 0。
   实测中它 100% 伴随低公有产权——这不是噪声，是公式的必然。
7. **它是宏观聚合模型，不是主体仿真。** 没有个体、没有网络、没有涌现。
8. **阶段轨道上的「商业资本主义」是前史标注。** 引擎的阶段判定最低只到
   「算法资本主义」——20000 组随机参数、74 万个年份快照里，「商业资本主义」
   出现 0 次。它在轨道上存在是为了讲述「我们从哪来」，不是引擎会返回的状态。
   同理，2024 年的技术渗透度恒为 0.4008（杠杆怎么拨都一样），所以时间轴停在
   2024 时显示的是「极化资本主义」而非「算法资本主义」。
9. **前三阶段只看技术渗透度。** 在越过 0.68 的闸门之前，制度、社会、意义杠杆
   完全不参与阶段判定。一个制度崩溃但技术推进的世界，与一个制度健全的世界，
   在前三阶段看起来一样。制度只在越线后才开始裁决方向——这是本模型最该被
   质疑的简化之一。
10. **界面已支持中英双语，但模型术语保持中文。** 标签、按钮、卡片标题会跟随
    DeepSeek Harness 的语言设置切换；而杠杆名、阶段名、结局名是模型契约的一部分
    （测试直接断言 `outcome.name === '算力封建制'`），因此始终显示中文。这是
    有意的：把模型语义翻译掉会让契约与测试失去意义。

---

## 它明确不做什么

- 不预测真实世界的具体事件
- 不给政策建议（它只展示「如果这样，会怎样」）
- 不做因果估计（政策在模型里是前馈插值）
- 不做道德判断（「自由人联合体」是一个参数组合的终点，不是价值主张）

---

## 数据与可复现

- 模型是**零依赖纯函数**，所有常数写在 `MODEL-CONTRACT.md` 里，由自动化测试守护。
- 模型体检页的采样报告固定随机种子，同一版本重跑结果完全一致。
- 六个预设剧本的终年读数被固化为断言——若某次改动让它们漂移，测试会立刻失败。
