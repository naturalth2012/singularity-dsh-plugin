# Singularity · AI 时代的社会形态演化

DeepSeek Harness 插件。在 Harness 里增加一个 **Singularity** 面板与侧栏图标，
提供可交互的历史推演器：把「AI 能否让资本主义陨落、共产主义如何到来」拆成
可拨动的杠杆、可拖动的时间轴，和六种可并排比较的结局。

> 这不是预言，而是一台**条件显微镜**。它不告诉你哪一年会发生什么，
> 它把「条件」摊开：同样的技术，不同的制度选择，结局相差数倍。

版本历史见 [CHANGELOG.md](CHANGELOG.md)｜模型契约见 [MODEL-CONTRACT.md](MODEL-CONTRACT.md)

## 安装

**方式一 · 插件市场**：Harness → 插件 → 插件市场，搜索 **Singularity** 一键安装。

**方式二 · npm**：

```sh
dsh plugin --profile <profile> add singularity-dsh-plugin
```

**方式三 · GitHub 源码**（免构建，无运行时依赖）：

```sh
dsh plugin --profile <profile> add github:<你的用户名>/singularity-dsh-plugin
```

装好后刷新页面（F5）即可，无需重启。

## 引擎语义分区（v1.0.1）

引擎按终年状态把任何参数组合划入三个互斥分区，结局由分区决定：

| 分区 | 条件（终年） | 结局 |
|------|------|------|
| **毁灭区** | `devastation > 0.5`（冲突真实摧毁有效产出） | 文明崩解（物理入口，先于一切裁决） |
| **裁决区** | 技术渗透度 ≥ 0.68 且未毁灭 | 引力最高者决定：算力封建 / 社会民主主义 / 共产主义谱系 |
| **悬置区** | 渗透度 < 0.68 且未毁灭 | 停滞的资本主义（带伤版：devastation > 0.25 时文案不同） |

引力数值永远在计算，但只有裁决区里「引力最高者 = 实际结局」成立；
悬置区的引力是**悬置**的——诊断与三岔路口页会如实区分这两种状态（不再输出「据此判定」的假因果）。
共产主义谱系的内部分档仍由社会化度闸门 0.48 决定。
已知非对称：崩解引力的增益系数（1.8）高于其他三条路径，理由与讨论见 [AUDIT-FIXES.md](./AUDIT-FIXES.md) P1-2。

## 核心机制

模型里最硬的一条设定是**唯一裁决入口**：当技术渗透度越过 `0.68` 且社会未被对抗摧毁
（`devastation ≤ 0.5`），四条引力（算力封建 / 社会民主 / 共产主义 / 文明崩解）中最高者即为实际结局；
`stage_of`、`resolve_outcome` 与三岔路 UI 共用同一个 `decide_path()`，
界面显示的引力百分比不再与结果脱节。

共产主义引力胜出时，「社会化度」（公共产权 45% + 再分配 35% + 全球协同 20%）
只决定走到哪一步：低于 `0.48` 则停在「未竟的过渡」，否则递进到自由人联合体。

资本主义不是「被打倒」，而是**没能及时改写自己** —— 这就是陨落的机制本身。

| 情景 | 结局 | 窗口 |
|------|------|------|
| 基准线 | 算力封建制 | 2031–2036 错过 |
| 社会民主主义 | 社会民主主义终点 | 2031–2036 错过 |
| 算力封建制 | 算力封建制 | 2031–2036 错过 |
| 计划性转型 | 共产主义初级形态 | 2031–2044 跨过 |
| 崩解 | 文明崩解 | 2031–2036 错过 |
| 全域共享 | 自由人联合体 | 2031–2041 跨过 |

六条路径的技术条件几乎相同，结局却完全相反。

## 结构

```
singularity-plugin\
├── package.json         # dsh.bundle.patch + dsh.client(platform: web)
├── cordis.patch.yml     # 插入 singularity 行
├── index.js             # Host 半：apply() 空实现（渲染在 Client）
├── client.js            # Client 半：引擎 + 六个视图 + SVG 图表
├── icon.svg             # 插件图标（自绘，无第三方素材）
├── locale\en.json       # 显示用标题与描述
├── locale\zh.json
└── tests\
    ├── engine.test.cjs  # 引擎一致性与三项修复断言（26 项）
    └── mount.test.cjs   # 模块契约与渲染冒烟（20 项）
```

Client 与 Host 之间**没有** RPC：引擎是纯函数，直接在浏览器里算，
所以拨动杠杆即时重算，不受会话状态影响。

## 挂载点

- `main`（keyed）→ key `singularity`，承载整个面板
- `sidebar.panellist`（list）→ id `singularity`，order 30，提供图标与标签

两者 id 相同：`sidebar.panellist` 的每个 list id 对应一个 `main` 面板 key，
侧栏按钮由宿主渲染并接管面板切换。

## 样式

只用 `--dsw-alias-*` 主题 token，自动跟随明暗主题；
阶段与图表使用数据色（`#4f8cff` / `#22c98a` 等），属于图示用色，不参与主题切换。

## 模型契约

模型的全部假设——时间轴、14 杠杆、派生指标公式、三区裁决语义、四条引力、
闸门常数、阶段轨道、已知非对称与局限——写在 **[MODEL-CONTRACT.md](./MODEL-CONTRACT.md)**。
它是一份**可被质疑的清单**：每个系数都可以被指出问题，第 9 节专门列出模型
自己知道的最薄弱之处（`COLLAPSE_GAIN=1.8` 无实证依据、社民路径上限被低估、
模型是前馈推演而非动力学系统）。

## v1.0.1 模型修正（2026-11-25）

对抗性审计（见 `scripts/audit-probe.cjs`、`audit-probe2.cjs`）发现三处
「界面在说谎」级缺陷，已修复：

1. **引力/结局脱钩**：引擎改为**三区裁决语义**（毁灭区 / 裁决区 / 悬置区）。
   旧版在技术渗透未过线时仍输出「引擎据此判定」的假因果；现在悬置区如实
   声明「引力悬置，历史尚未进入裁决」。随机空间中的假因果案例 783 → 0。
2. **崩解缺少物理入口**：`devastation > 0.5` 时先于引力裁决直入文明崩解，
   使「尚未分岔就被摧毁」的历史可被表达；停滞桶拆出「带伤的停滞」文案，
   高冲突世界不再拿到「生产力略有提升」的正面描述。
3. **`inWindow` 死代码**：修复 `win.type === 'passed' === false` 的运算符
   优先级 bug，passed 型窗口年份恢复标记（0 年 → 14 年）。

## 一句话

模型里每个系数都是一次可辩论的判断。它的价值不在于精确，而在于**可被反驳**：
把公共产权拉到 1.0 却发现走不到共产主义（丰裕度与意义供给没跟上），
或把技术拉到最低、看着资本主义「没有陨落」—— 这种「没有发生」本身也是结论。
