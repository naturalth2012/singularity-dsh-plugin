# Singularity · AI 时代的社会形态演化

DeepSeek Harness 插件。在 Harness 里增加一个 **Singularity** 面板与侧栏图标，
提供可交互的历史推演器：把「AI 能否让资本主义陨落、共产主义如何到来」拆成
可拨动的杠杆、可拖动的时间轴，和六种可并排比较的结局。

> 这不是预言，而是一台**条件显微镜**。它不告诉你哪一年会发生什么，
> 它把「条件」摊开：同样的技术，不同的制度选择，结局相差数倍。

---

## 使用

安装后，左侧栏出现 **Singularity** 图标（order 30，在 dsh-context 之后）。
点击进入全宽面板，顶部六个标签：

| 标签 | 内容 |
|------|------|
| **历史长河** | 2024–2060 年份滑块、七阶段轨道、8 项实时指标、演化曲线、条件触发事件 |
| **演化引擎** | 14 个杠杆（技术/制度/社会/摩擦）；技术有自主趋势，制度由你设定；实时敏感度与结构归因 |
| **三岔路口** | 三种路径引力场实时计算，标出胜出者；路径对照表 |
| **指标矩阵** | 13 项终局指标、4 组轨迹图、逐年数据表（点击跳转到该年） |
| **情景对比** | 六情景并排：结局、发展 D、丰裕、自由、不平等、窗口期；可一键载入 |
| **理论底座** | 三重动力、本路径判定、两条经典引文 |

## 核心机制

模型里最硬的一条设定是**唯一裁决入口**：当技术渗透度越过 `0.68`，
四条引力（算力封建 / 社会民主 / 共产主义 / 文明崩解）中最高者即为实际结局；
`stage_of`、`resolve_outcome` 与三岔路 UI 共用同一个 `decide_path()`，
界面显示的引力百分比不再与结果脱节。

共产主义引力胜出时，「社会化度」（公共产权 45% + 再分配 35% + 全球协同 20%）
只决定走到哪一步：低于 `0.48` 则停在「未竟的过渡」，否则递进到自由人联合体。

资本主义不是「被打倒」，而是**没能及时改写自己** —— 这就是陨落的机制本身。

| 情景 | 结局 | 窗口 |
|------|------|------|
| 基准线 | 算力封建制 | 2031–2036 错过 |
| 社会民主主义 | 社会民主主义终点 | 2031–2036 错过 |
| 算力封建制 | 算力封建制 | 2031–2036 错过 |
| 计划性转型 | 共产主义初级形态 | 2031–2044 跨过 |
| 崩解 | 文明崩解 | 2031–2036 错过 |
| 全域共享 | 自由人联合体 | 2031–2041 跨过 |

六条路径的技术条件几乎相同，结局却完全相反。

## 结构

```
singularity-plugin\
├── package.json         # dsh.bundle.patch + dsh.client(platform: web)
├── cordis.patch.yml     # 插入 singularity 行
├── index.js             # Host 半：apply() 空实现（渲染在 Client）
├── client.js            # Client 半：引擎 + 六个视图 + SVG 图表
├── icon.svg             # 插件图标（自绘，无第三方素材）
├── locale\en.json       # 显示用标题与描述
├── locale\zh.json
└── tests\
    ├── engine.test.cjs  # 引擎一致性与三项修复断言（26 项）
    └── mount.test.cjs   # 模块契约与渲染冒烟（20 项）
```

Client 与 Host 之间**没有** RPC：引擎是纯函数，直接在浏览器里算，
所以拨动杠杆即时重算，不受会话状态影响。

## 挂载点

- `main`（keyed）→ key `singularity`，承载整个面板
- `sidebar.panellist`（list）→ id `singularity`，order 30，提供图标与标签

两者 id 相同：`sidebar.panellist` 的每个 list id 对应一个 `main` 面板 key，
侧栏按钮由宿主渲染并接管面板切换。

## 样式

只用 `--dsw-alias-*` 主题 token，自动跟随明暗主题；
阶段与图表使用数据色（`#4f8cff` / `#22c98a` 等），属于图示用色，不参与主题切换。

## 自检

```bash
node tests\engine.test.cjs   # 26/26
node tests\mount.test.cjs    # 20/20
```

- `engine.test.cjs`：从 `client.js` 中截取 factory 体，在 Node 里执行，
  断言六情景结局、年份跨度、指标落在 [0,1]、事件单调、边界参数、敏感度排序、归因非空，
  以及 **v1.1 三项修复**：引力胜出者=结局（含随机 200 组）、教育不改变渗透度/结局、
  冲突真实损毁生产力。
- `mount.test.cjs`：桩掉 DOM 与模块加载器，断言 `__ModuleLoader__.load` 被调用、
  `apply` 向 `main` 与 `sidebar.panellist` 注册、样式表注入与卸载、
  组件渲染不抛异常、样式仅用主题 token。

**这不是视觉验证。** 视觉表现需在 Harness 页面内实际查看。

## v1.1 模型修正（2026-11-10）

数值审计（见独立版 `singularity\tests\audit.py`、`audit2.py`）发现旧模型三处
「界面在说谎」级缺陷，插件引擎与 Python 引擎已同步修复：

1. **引力场是唯一裁决入口**：新增文明崩解为第四条引力，`decide_path()` 被
   `stageOf` / `resolveOutcome` / 三岔路 UI 共用；随机 200 组一致性 200/200。
2. **教育悖论消除**：拆分毛替代压力 `gross` 与净替代率，技术渗透只由 `gross`
   与不受损毁的技术潜力推进；教育 0/0.5/1.0 结局一致。
3. **崩解叙事兑现**：`devastation = f(conflict, shock)` 真实进入
   `productivity`，崩解情景 2060 生产力 0.124（基准 0.847）。

附带修正：算力封建引力改由寡头俘获主导（旧版把「产权仍私有」误判为封建化）、
补齐 `planned_transition` 的 `solidarity`、归因文案随损毁自适应。

**仍未修**：时间尺度幂只影响窗口年份、D 不参与阶段判定、闸门后部分杠杆惰性、
阈值无外部校准。详见独立版 README 的审计小节。

## 卸载

在 Harness 的插件页停用或移除 **Singularity**；移除后侧栏图标与面板一并消失。

## 一句话

模型里每个系数都是一次可辩论的判断。它的价值不在于精确，而在于**可被反驳**：
把公共产权拉到 1.0 却发现走不到共产主义（丰裕度与意义供给没跟上），
或把技术拉到最低、看着资本主义「没有陨落」—— 这种「没有发生」本身也是结论。
